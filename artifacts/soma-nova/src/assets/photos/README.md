# Photos

Drop Emily's real photos here using the file names listed in `src/content/photos.ts`
(jpg, jpeg, png, webp or avif). They are picked up automatically. Until a file exists,
the site shows a sand-colored placeholder describing the shot. The hero also accepts an
optional `hero-mobile.*` file for a 4:5 phone crop.
No stock, AI-generated or old iStock images.
